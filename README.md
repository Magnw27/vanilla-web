# vanilla-web

A framework-free portfolio experiment built from scratch with HTML, CSS and JavaScript.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Web APIs only

## Motion
Custom loader, scroll reveal choreography, cursor glow, magnetic interactions, 3D card tilt, animated grid, marquee, orbital artwork, micro-interactions and reduced-motion support.

No React. No Vite. No Tailwind. No animation library. No build step.
